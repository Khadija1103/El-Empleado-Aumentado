PUNTO DE PARTIDA

Tener datos no significa tener información.

Una organización puede tener miles de datos y, aun así, no saber con claridad qué está ocurriendo.

Los datos son registros de hechos, eventos, mediciones o características. Por sí solos pueden tener poco significado para quien necesita tomar una decisión.

Cuando esos datos se organizan, relacionan, comparan y contextualizan, se convierten en información que permite comprender una situación.

El objetivo de este módulo no es aprender a acumular datos. Es aprender a utilizarlos como evidencia para trabajar mejor.

01 CAPACIDAD · ESTRUCTURA DE INFORMACIÓN

Organizar datos

Antes de analizar información es necesario comprender su estructura. Organizar datos implica establecer una forma consistente de almacenar, clasificar y relacionar los registros para que puedan ser consultados, comparados y analizados. Una estructura adecuada reduce ambigüedades y facilita el uso posterior de herramientas como Excel, Power BI, SQL o sistemas de Inteligencia Artificial.

ASPECTOS CLAVE
  • Definir qué representa cada columna, registro o variable.
  • Mantener formatos consistentes para fechas, nombres, cantidades y categorías.
  • Evitar mezclar datos, encabezados, totales y comentarios dentro de la misma estructura.
  • Utilizar identificadores que permitan relacionar registros cuando sea necesario.
EJEMPLO

Una base de solicitudes puede contener fecha, área, responsable, tipo de solicitud, estado, tiempo de respuesta y fecha de cierre. Cuando estas variables están correctamente estructuradas, resulta mucho más sencillo calcular indicadores y analizar el comportamiento del proceso.

Criterio profesional Una buena estructura de datos debe responder a cómo serán utilizados posteriormente. Organizar no significa simplemente ordenar columnas; significa diseñar una estructura que conserve el significado de la información y facilite el análisis posterior.
02 CAPACIDAD · CALIDAD DE DATOS

Validar datos

La validación consiste en comprobar si los datos cumplen las condiciones necesarias para ser utilizados con confianza. Un conjunto de datos puede estar completo y aun así contener errores de formato, duplicados, valores imposibles o registros inconsistentes.

¿QUÉ DEBE REVISAR?
  • Valores faltantes o registros incompletos.
  • Registros duplicados.
  • Fechas fuera del período analizado.
  • Valores atípicos que requieran explicación.
  • Diferencias entre fuentes que deberían contener información equivalente.
EJEMPLO

Si una empresa analiza tiempos de atención y encuentra registros negativos, fechas imposibles o solicitudes cerradas antes de haber sido creadas, el problema no está en el cálculo del indicador. Está en la calidad de los datos que alimentan ese cálculo.

Criterio profesional Un dato incorrecto puede producir un resultado matemáticamente correcto pero profesionalmente equivocado. La validación debe realizarse antes de interpretar indicadores o tomar decisiones basadas en ellos.
03 CAPACIDAD · INDICADORES

Medir lo que importa

Medir significa establecer una forma objetiva de observar el comportamiento de una variable relacionada con un proceso, objetivo o resultado. Un buen indicador no se elige porque sea fácil de calcular, sino porque aporta información útil para comprender una situación o controlar un proceso.

UN INDICADOR DEBE TENER
  • Una definición clara de lo que mide.
  • Una fuente de datos identificable.
  • Un período o frecuencia de medición.
  • Una unidad o fórmula de cálculo.
  • Un propósito relacionado con el proceso o el objetivo.
EJEMPLO

En un proceso de atención, el número total de solicitudes es un dato. El porcentaje de solicitudes atendidas dentro del tiempo establecido es un indicador que permite evaluar un aspecto concreto del desempeño del proceso.

Criterio profesional Medir más variables no necesariamente mejora el control. Un exceso de indicadores puede dificultar la identificación de lo verdaderamente importante. La selección debe responder a las decisiones que la organización necesita tomar.
04 CAPACIDAD · INTERPRETACIÓN

Interpretar resultados

Interpretar significa comprender qué representa un resultado dentro de un contexto determinado. Un indicador puede mostrar que algo cambió, pero por sí solo no explica necesariamente por qué cambió ni qué acción debería tomarse.

ANTES DE CONCLUIR, PREGUNTE
  • ¿Respecto de qué período o referencia estoy comparando?
  • ¿El cambio es significativo o corresponde a una variación normal?
  • ¿Qué factores externos pueden haber influido?
  • ¿La información disponible permite explicar el comportamiento?
  • ¿Qué evidencia adicional necesito antes de actuar?
EJEMPLO

Si un indicador de productividad disminuye durante un mes, no es suficiente afirmar que el equipo "rindió menos". Es necesario revisar volumen de trabajo, ausencias, cambios en la operación, complejidad de los casos, disponibilidad de recursos y cualquier otra variable que pueda explicar la variación observada.

Criterio profesional La interpretación transforma un resultado numérico en conocimiento útil. Sin contexto, un indicador puede conducir a conclusiones apresuradas. El objetivo del análisis no es producir más gráficos, sino comprender mejor una situación para actuar con mayor fundamento.
